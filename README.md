# Sales Management System

A web-based Sales Management System developed using PHP, MySQL, HTML, CSS, and JavaScript. The system helps businesses manage products, sales, inventory, customers, suppliers, and generate reports efficiently.

## Features

- User Authentication (Admin & Seller)
- Product Management
- Inventory/Stock Management
- Sales Recording
- Customer Management
- Supplier Management
- Sales Reports
- Revenue Tracking
- Responsive User Interface
- Secure Database Operations

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
